# 账单 · 手机版

一个两个人用的家庭账单的手机网页版（iPhone 上「添加到主屏幕」后像一个 app）。
和电脑版共用同一个云端，账单在手机上用账本密码解密；云端和放网页的网站都只看到乱码。

- 这个仓库里**没有**任何连接设置或密码。第一次打开要用一个设置链接（只发给自己人），
  连接设置存在那台手机上。
- 网页是纯静态文件，放在 GitHub Pages，不需要编译。
- 加密：scrypt（[@noble/hashes](https://github.com/paulmillr/noble-hashes) 2.0.1，见 `vendor/`）推导密钥，
  浏览器自带的 AES-GCM 加解密，格式和电脑版完全一样。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架（含 Content-Security-Policy） |
| `app.js` | 界面：账本列表、解锁、账单、花销、类型、自动同步 |
| `core.js` | 账单规则（状态、花销按月、输入检查、账单加解密） |
| `crypto.js` | 密钥推导和加解密 |
| `store.js` | 云端接口、连接设置、设置链接 |
| `style.css` | 样式 |
| `sw.js` | 离线缓存（网站慢或连不上也能打开） |
| `static/` | 图片、动画视频、图标 |
| `tests/crypto_test.html` | 和电脑版互通的加密测试（`vectors.json` 由电脑版生成） |

## 更新

改了网页文件后，把 `sw.js` 里的 `VERSION` 加一，再推送。手机上下次打开会在后台取新版，
再下一次打开就是新版。
